# SD SPI transport regression

Run `make -C bench/sd test` from the repository root. Requires Python 3, a native C compiler, and
GHDL with VHDL-2008 support. Products go to `/tmp/minimig-sd-tests`; override
`BUILD_DIR` or `GHDL` if needed.

The test instantiates production `rtl/host/cfide.vhd` at approximately 114.28 MHz
with the supported boards' direct SD connection (`spimux=0`, `sd_ack=1`). It reads
the slow and fast divider values from both firmware headers and checks:

- initialization SCK at or below 400 kHz with CS both asserted and deasserted;
- transfer SCK at or below 25 MHz and byte loopback at both speeds;
- exactly 4096 clocks for direct sector transfers;
- default-on idle clocks with MOSI high and every SPI device deselected;
- safe reset frequency, full SCK pulses and clock parking before chip selection;
- no extra clocks across software gaps while any shared SPI device is selected;
- completed receive bytes remain unchanged during idle clocking;
- both enabled and disabled settings of `sd_free_running` and `havespirtc`;
- unused selects 2/3 never suppress idle clocks, and select 7 suppresses them
  and selects the SD/RTC receive input only when the RTC is enabled;
- pin-level replay of command/read/write bytes generated by the production
  runtime firmware and command/read bytes from the production bootstrap. Replay
  inserts software gaps to detect stray selected clocks. Runtime initialization,
  including CSD, is conservatively replayed at the slow divider; transfers use
  the matching firmware's fast divider.

A stub binds the unrelated AUX FIFO; AUX SPI and USB HID are disabled. GHDL may
warn about unbound USB components in disabled generate branches. This does not
model a card or establish electrical setup/hold margins or FPGA timing closure.
Firmware command/CS sequences are tested in `fw/ctrl_832/tests/mmc_error_test.c`.

## Free-running clock option

`cfide.sd_free_running` is an integer generic defaulting to `1`. Set it to `0`
to synthesize the previous clock behavior without idle clocking or its bus-write
alignment logic. With the option enabled, reset starts at a safe initialization
divider (`0xEF`) and MOSI high before firmware programs its divider.

The clock is shared with Minimig's IDE/floppy and OSD interfaces and optional
RTC. It free-runs only when all connected device selects are inactive. The
constant select mask is `0x72` without RTC (bits 1/4/5/6) or `0xF2` with RTC
(bits 1/4/5/6/7). Bits 0/2/3 do not affect idle clocking. A disabled RTC select
also has no effect on the receive mux. Unused select outputs are held high,
allowing their state and write logic to be pruned even at the module boundary. CS register writes
wait for the idle high half-cycle to finish, so selecting a device neither
creates a partial clock pulse nor clocks data before its first transfer.
Selected transactions remain byte paced: the firmware holds SD CS low between
command bytes, response polls and sector bytes, so continuously clocking those
gaps would lose response/data bits. Firmware completion bytes remain valid with
the option either on or off. No firmware changes are required.
