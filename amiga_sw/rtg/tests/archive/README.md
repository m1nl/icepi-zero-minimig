# Historical driver tests

Recovered from `/tmp` during the RTG work and originally collected under
`bench/archive/early-reproductions/`. The original-source SHA-256 digests and
current paths are recorded in `../../../../bench/archive/sources.json`.

`test_driver_repeat.py`, `test_driver_clocks.py`, `rtg_driver_repeat.asm` and
`rtg_driver_repeat_tb.v` target earlier interfaces/mode policies. The scripts
also contain their original temporary paths. They are preserved unchanged
for reference, not run as part of the current driver suite.

Use `make -C amiga_sw/rtg test` for the maintained tests.
